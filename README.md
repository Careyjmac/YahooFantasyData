# YahooFantasyData

This repository contains Python scripts for analyzing Yahoo fantasy football data statistics. It uses the [Yahoo Fantasy Sports API](https://developer.yahoo.com/fantasysports/guide) via the [YFPY Python wrapper library](https://yfpy.uberfastman.com/).

To get started with the code, follow the [setup instructions](https://yfpy.uberfastman.com/readme/#setup) in YFPY documentation.
